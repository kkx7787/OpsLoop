## 병합과 영상·발표 연결

PR 순서는 **#104 → #106 → #108 → #110 → #112 → #114**다. 뒤 PR의 현재 base는 앞 개발 브랜치다. 앞 PR 병합 뒤 다음 PR을 main 대상으로 바꾸고 차이를 다시 확인한다. squash 병합이면 조상 이력 차이도 확인한다. 자동 병합하지 않았다. 최종 main의 실행 코드가 검증한 판과 달라지면 영향 범위를 재검증한다.

영상은 약 6분 50초 무음 자막 구성과 `대시보드 → 구성 → 노드 편입 → 근거 확인·차단 요청·판정 기록 → 장애 전환 → 복원 → 한계` 흐름을 유지한다. 다만 주소·로고·담당 영역·data01 지표가 보이는 장면은 새 화면과 맞춰야 한다. 10/02 원본을 쓸 때는 그때 측정한 판과 날짜를 표시하고 새 HTTPS 시험 수치를 옛 원본 위에 덮어 쓰지 않는다.

장애 전환 자막은 첫 성공 묶음 시작, 연속 20회 확인, HAProxy 장애 감지 시각을 구분한다. 세션 인증이 유지됐다는 결과를 WSS 연결 단절이 없었다고 바꾸지 않는다. 복원은 격리 DB·서비스 사용 확인 범위이고 전체 새 VM·인증서 재구성으로 설명하지 않는다.

PPT는 시스템 구성과 실제 확인한 동작을 먼저 설명하고, 조건·미시험·상시 운영 전 조치를 마지막에 명시한다. 사용자 편집 중인 WBS 파일은 이번 작업에서 수정하지 않았다.
