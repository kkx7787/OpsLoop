## 범위와 해석

- 리플레이 결과는 저장된 사건의 동일 구간 비교다. 웹에서 원문을 재실행하거나 규칙을 변경하는 기능은 아니다. 한 버전의 결과가 없으면 0건으로 간주하지 않는다.
- 실행 이력의 신규 생성 수는 전체 결과 수와 다르다. 버전마다 관측 기간이 달라 전체 합계 감소를 성능 개선으로 표시하지 않는다.
- 노드 목록은 등록 에이전트 기준이다. 기존 허니팟·디코이의 S3 수집 경로를 노드 등록으로 바꾸지 않는다.
- 기존 노드 재등록 시 첫 적재 시각이 과거 기록일 수 있다. 설치 후 형식 변환·규칙 적용 확인은 기존 Ansible 첫 수신 점검으로 수행한다.
- 감사 화면은 현재 감사 뷰의 차단 변경 및 콘솔 토큰 발급·취소 범위를 표시한다. CLI 토큰 관리의 파일 원장, 모든 계정·권한 변경을 통합한 화면은 아니다.
- 알림 설정·출발지 분석·보고서·계정 화면은 #27 범위 밖이다.
