원문은 `failover/raw.tar.xz`, 원문 파일 해시는 `failover/raw-sha256.json`, 기존 계측 결과는 `failover/results.json`, 위 표의 추출값은 `failover/metrics.json`이다. 모든 회차의 계측 도구 파일 해시는 같으며, 도중의 저장소 HEAD 변경은 #113 도구 커밋이다. 실행 앱 이미지는 바뀌지 않았다.
