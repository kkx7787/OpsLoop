## 문제와 변경

담당 배정이 실제 판정자 확인 목적과 맞지 않았고, 주목 CVE의 미확인이 사람의 판정 대기로 읽혔습니다. 자산 조사가 실패한 뒤 다음 정기 회차까지 복구되지 않는 실행 방식과 추가 노드의 비영속 수집 경로도 보완합니다.

- 사건 목록에 최신 판정과 같은 기록의 판정자·저장 시각을 표시합니다. 담당 배정 UI와 숨은 URL 필터를 제거하고 전체 미판정으로 연결합니다. 기존 API·이력·동시 수정 충돌 방지는 유지합니다.
- CVE의 자산 해당 여부, 마지막 성공 수집·최근 시도·대조 시각을 구분합니다. 규칙 품질 집계와 운영자의 후보 편집·리플레이·승격 절차를 화면에서 설명합니다.
- 자산 조사에 로그인 시·15분 주기 실행 필요 확인, 실패 재시도, 중복 실행 방지, 시간 제한·시계 검사를 추가합니다. AWS 인증 실패도 자산별로 기록하며 이전 성공 결과를 보존합니다.
- 추가 노드를 방화벽 수집 허용 목록·Ansible 인벤토리·자산 조사 대상에 일치시킵니다. 구형 집행기 시험의 버전 인자를 현 계약에 맞춥니다.
- 화면 설계·운영 문서·개발 동결 기록을 갱신합니다. 과거 실측값을 수정 판의 측정값으로 바꾸지 않습니다.

## 검증

- 화면 전체 시험 1,111개 통과. 마지막 문구·미사용 UI 제거 후 사건 상세 시험 70개, 빌드·린트 통과.
- API 764개 통과(격리 PostgreSQL 포함). 최신 판정자·시각이 동일 기록에서 반환되는 회귀시험 추가.
- 자산 조사·스케줄 시험 34개 통과. 정기 경계, 실패 복귀, 잘못된 상태, 시계 오류, 시간 제한을 검사.
- 수집·파싱·탐지·집행·복원·백업·인프라 시험 실행. 환경 의존 시험의 건너뜀은 별도로 기록했으며 새 장애 전환/RTO 측정을 뜻하지 않습니다.
- 주요 메뉴를 로컬 시험 데이터로 조회하고 390px·1100px·1440px 표시를 확인. 운영 데이터로 수행한 쓰기 시험과 혼동하지 않습니다.

## 적용 및 남은 조건

앱 화면/API는 이 PR 병합 후 배포가 필요합니다. 운영 수집 경로와 자산 조사 실행기는 별도로 복구·확인했습니다. AWS 인증 갱신과 꺼진 VM 기동은 자동화하지 않습니다. 기존 배정 API·데이터는 호환성을 위해 남깁니다.

Loki 보존 기간 결정과 실제 원본 삭제 적용은 #109에 남깁니다. LLM·규칙 편집기 등 신규 기능, 사용자 편집 중인 WBS·발표 자료는 포함하지 않습니다. 상세 운영 로그는 로컬에 보관합니다.
