# #107 화면·브랜딩 개발 검증

2026-10-03, 운영과 분리한 로컬 표본 서버(127.0.0.1:18766, GET만 허용)로 확인했다. 화면 속 사건·지표·계정은 표본이다. 로그인 HTML은 실제 app/web.py 템플릿에서 추출하고 제출은 차단했다. 운영 배포나 DB 통합 시험의 증거가 아니다.

- 화면: 70개 파일 1,104개 통과
- 웹 계층: 86개 중 85개 통과, asyncpg 드라이버 예외형 1개는 로컬 패키지 부재로 건너뜀
- TypeScript·Vite 빌드 및 린트 통과
- 로그인 로고, 16~64px favicon의 밝고 어두운 배경, 1440·1024·390px 대시보드 확인
- 1024px: innerWidth=1024, documentElement.clientWidth=1009(스크롤바 제외), scrollWidth 초과 없음
- 390px: 가로 넘침 없음, 내 담당 미판정 링크와 접힌 보호 대상 표시

새 로고 접근 범위, 일반 파일 인증, 입력 HTML 이스케이프를 시험했다. 기존 DB 시험은 사용자 디스크 정리로 Docker를 중지한 동안 재실행하지 않았다.
