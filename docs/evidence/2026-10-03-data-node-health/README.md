카드/띠 DB 시험은 같은 수집 결과의 경고 일치, 누락·조회 권한 없음에서 읽기 트랜잭션이 계속되는지, 오래됨을 정상으로 보이지 않는지를 검증한다. 스키마 시험은 한 행 갱신, 역할별 읽기/쓰기/삭제 제한, 반복 적용을 확인한다.

스크린샷은 **읽기 전용 표본 데이터**다. 루트/DB 용량 부족과 Loki 측정 실패를 일부러 함께 넣었으며 운영 data01의 상태가 아니다. 헤더의 `수집 정상`과 용량 경고를 구별해서 표시한다. 등록 노드는 빈 표본이다.

초기 앱·화면·복원 시험은 새 자원 상태와 표 개수에 맞지 않는 기존 기대값 때문에 실패해 수정했다. 수집기 전체 실행은 기존 `test_gate.py`의 가짜 psycopg2에 Error가 없어 후속 모듈 import가 실패했고 예외형을 보완했다. 첫 로컬 수집기 실행은 샌드박스 소켓 제한으로 실패해 격리 Docker에서 다시 실행했다. 최종 결과만 이 폴더에 보존하며 초기 로그는 로컬 output에 남겼다.

앱의 AnyIO 스트림 및 복원 시험의 파일 ResourceWarning은 남아 있다. 시험 실패는 아니며 운영 런타임 자원 누수로 확인한 결과도 아니다.

DB 암호는 시험 컨테이너에 읽기 전용 파일로 넣었고 로그나 이 폴더에 복사하지 않았다. `SHA256SUMS`는 이 파일과 시험 로그·화면·Loki 검증 메타데이터를 포함한다.
