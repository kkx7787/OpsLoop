## 반영 범위

- README에 철거 상태, p4 운영 배포와 p5 미배포·미평가, 종료 후 정합성 보완·검증 기록을 구분했다. 과거 성과 수치는 바꾸지 않았다.
- AWS·VMware 문서의 첫 부분에 철거 후 재구축 준비와 새 이미지·키·자원 식별자 필요 조건을 넣었다. 기존 구축 명령을 새 계정에서 그대로 실행할 수 있다고 표현하지 않는다.
- 삭제된 S3 버킷의 import 블록 세 개를 제거했다. S3 리소스·IAM 정책의 실행 정의는 변경하지 않았다.
- 옛 EC2 설치·백업·수집 구성과 SQLite 분석 도구에 레거시 안내를 붙였다. 실행 내용은 바꾸지 않았다.
- v10 drawio와 PNG 세 장을 등록했다. PNG는 v10의 출력본이 아닌 발표용 개념도라 [구성도 안내](../../구성도-안내.md)에서 용도·조건을 구분했다. 기존 도면·이미지 내용은 유지했다.
- 작업 산출물·개인 문서를 공개 대상에서 제외하고, 브랜치 전략에 main 기준 단일 PR 준비 원칙을 명시했다.
